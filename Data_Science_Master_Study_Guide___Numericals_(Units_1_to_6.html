Data Warehouse Architecture & Preprocessing

Consolidating multi-source operational records via 3-tier ETL warehousing and transforming noisy attributes into clean, scaled inputs for machine learning.

02.1 3-Tier Data Warehouse Architecture, ETL & OLAP

5-Mark Master Answer
1. Definition & Core Properties (1 Mark)

A Data Warehouse (DW) is a subject-oriented, integrated, time-variant, and non-volatile collection of data supporting management decision-making. Unlike an Operational Data Store (ODS) or raw Data Lake, it stores historical, schema-verified analytical records.

2. Key Components & Terms (1 Mark)
  • Data Lake vs. Data Mart: A Data Lake holds raw structured/unstructured dumps; a Data Mart is a department-specific subset (e.g., Finance or Sales).
  • Fact Table: Central table in a Star/Snowflake schema holding quantitative measures (loan amount, #transactions, balance) and foreign keys to dimension hierarchies (e.g., branch → city → state).

Advantages: Unified historical truth, fast aggregate OLAP queries (Roll-up, Drill-down, Rotation/Pivot Table). Disadvantages: High upfront ETL maintenance cost and latency during batch materialized-view refresh. Hospital & Banking Example: Tracking multi-year patient admissions or loan balances across branch → city → state hierarchies.

02.2 Five Core Data Preprocessing Techniques

5-Mark Master Answer
1. Concept & Need (1 Mark)

Real-world data is incomplete (missing attributes), noisy (errors/outliers), and inconsistent (naming discrepancies). Data Preprocessing improves model accuracy and convergence speed ("Garbage In, Garbage Out").

2. Five Preprocessing Pillars (3 Marks)
Technique Core Mechanism & Methods
1. Data Cleaning Fills missing values (mean/median imputation, global constant), smooths noisy data (binning, regression, clustering), and removes outliers.
2. Data Integration Merges multiple databases/cubes; resolves entity identification, schema conflicts, and correlation-based redundancy ($\chi^2$ / Pearson).
3. Data Reduction Produces a reduced volume with identical analytical results via dimensionality reduction (PCA), numerosity reduction, and data cube aggregation.
4. Data Transformation Scales and reshapes attributes using Min-Max Normalization, Z-Score Standardization, and attribute construction.
5. Data Discretization Converts continuous numerical attributes into categorical intervals or binary flags required by Decision Trees and Association Rule Mining.
3. Retail Case Study (1 Mark)

Retail Customer Preprocessing: Cleaning null postal codes, standardizing customer incomes via Z-score for k-NN/SVM, and discretizing Age into brackets (18–25, 26–40, 41+) for market basket profiling.

Numerical Lab 2A

Normalization (Min-Max & Z-Score) & Binning Smoothing

Interactive Calculator

Exam Reference Formulas

$$v'_{\text{minmax}} = \frac{v - \min_A}{\max_A - \min_A}(\text{new\_max}_A - \text{new\_min}_A) + \text{new\_min}_A$$
$$v'_{\text{z-score}} = \frac{v - \mu}{\sigma}, \quad \text{where } \sigma = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(x_i - \mu)^2}$$

Worked Example (Sorted Price Data)

Given sorted values $X = [4, 8, 15, 21, 21, 24, 25, 28, 34]$ ($N=9$):
Min-Max $[0, 1]$ for $v = 21$: $\frac{21 - 4}{34 - 4}(1 - 0) + 0 = \frac{17}{30} = \mathbf{0.567}$.
Equal-Frequency Binning ($k=3$, depth $=3$):
Bin 1: $[4, 8, 15]$ (Mean $= 9.0$) → Boundaries $[4, 4, 15]$
Bin 2: $[21, 21, 24]$ (Mean $= 22.0$) → Boundaries $[21, 21, 24]$
Bin 3: $[25, 28, 34]$ (Mean $= 29.0$) → Boundaries $[25, 25, 34]$

Python Demo: Min-Max, Z-Score & Equal-Frequency Binning (Pandas / Scikit-Learn) 
import numpy as np
import pandas as pd
from sklearn.preprocessing import MinMaxScaler, StandardScaler

data = np.array([[4], [8], [15], [21], [21], [24], [25], [28], [34]])

minmax = MinMaxScaler(feature_range=(0, 1)).fit_transform(data)
zscore = StandardScaler().fit_transform(data)
bins = pd.qcut(data.ravel(), q=3, labels=["Low", "Medium", "High"])

print("Min-Max:", np.round(minmax.ravel(), 3))
print("Z-Score:", np.round(zscore.ravel(), 3))
print("Bins:   ", list(bins))

Classification & Regression

Predicting discrete class categories and continuous numeric outcomes, reinforced by worked Entropy, Information Gain, Gini Index, and Naïve Bayes derivations.

03.1 Classification vs. Regression & Classification Types

5-Mark Master Answer
1. Definition (1 Mark)

Classification is a supervised learning technique that maps input features from labeled training data to discrete categorical class labels. Regression models the relationship between predictor variables and a continuous numeric outcome by fitting a line or curve that minimizes vertical prediction error.

2. Three Types of Classification (1 Mark)
  • Binary Classification: Exactly two mutually exclusive states — class 0 (normal, e.g., not spam / cancer not identified) vs. class 1 (abnormal, e.g., spam / cancer detected).
  • Multi-Class Classification: More than two classes with no normal/abnormal hierarchy; each sample gets one label (e.g., eCommerce grouping: Electronics, Clothing, or Home Decor).
  • Multi-Label Classification: Assigns two or more non-exclusive labels simultaneously to one item (e.g., photo tagged "dog", "ball", and "park").
3. Comparison Matrix (2 Marks)
Parameter Classification Regression
Target Output Discrete / Categorical class labels Continuous real-valued numbers
Objective Find an optimal decision boundary Find a best-fit line or curve minimizing vertical residuals
Core Algorithms Logistic Regression, Decision Tree, Random Forest, k-NN, Naïve Bayes, SVM Simple/Multiple Linear Regression, Polynomial Regression, SVR, Ridge/Lasso
Evaluation Metrics Accuracy, Precision, Recall, F1-score, Confusion Matrix, ROC MSE, RMSE, MAE, R-squared ($R^2$)
4. Credit Card Default Case Study & Ethics (1 Mark)

03.2 Core Classifiers: Tree, Forest, k-NN, Naïve Bayes & SVM

5-Mark Master Answer
Algorithm Working Mechanism & Keywords Key Advantage / Trade-off
Decision Tree (CART) Hierarchical tree where internal Decision Nodes test attributes via ASM (Information Gain or Gini Index), branches represent outcomes, and Leaf Nodes emit predictions. Highly interpretable; prevents overfitting via Cost Complexity Pruning or Reduced Error Pruning.
Random Forest Ensemble method aggregating predictions from multiple diverse decision trees via majority vote (classification) or mean (regression). Corrects single decision tree overfitting and boosts stability.
K-Nearest Neighbors (k-NN) Instance-based learner measuring Euclidean distance to the $k$ closest training records and assigning the majority class. Zero training cost; sensitive to feature scaling (requires Unit II normalization).
Naïve Bayes Applies Bayes Theorem $P(A|B) = \frac{P(B|A)P(A)}{P(B)}$ assuming conditional independence among input features. Fast, effective on small datasets; ideal for text classification & sentiment analysis.
Support Vector Machine (SVM) Finds the optimal hyperplane in $N$-dimensional space that maximizes the margin between the nearest support vectors of each class. Strong in high-dimensional spaces; handles non-linear boundaries with kernels.

Clustering Algorithms & Customer Segmentation

Partitioning unlabeled observations into cohesive groups with high intra-cluster similarity and low inter-cluster similarity.

04.1 Four Clustering Paradigms & Case Study

5-Mark Master Answer
1. Definition (1 Mark)

Clustering is an unsupervised learning task that groups unlabeled objects into clusters such that points within the same cluster are maximally similar and points across different clusters are maximally dissimilar.

2. Four Algorithm Families (3 Marks)
Family Representative Algorithms Mechanism & Strengths
Centroid-Based (Partitioning) K-Means, K-Medoids Minimizes within-cluster sum of squares (WCSS) around $k$ centroids. Fast $O(nkt)$; assumes spherical clusters.
Density-Based DBSCAN, OPTICS Groups dense regions ($\ge \text{MinPts}$ within $\varepsilon$ radius); detects arbitrary shapes and isolates noise outliers.
Connectivity-Based (Hierarchical) Agglomerative (Bottom-Up), Divisive (Top-Down) Builds a Dendrogram using Single, Complete, or Average linkage; no pre-set $k$ needed.
Distribution-Based Gaussian Mixture Models (GMM) Models clusters as overlapping probability distributions via Expectation-Maximization (soft cluster assignment).

Unit 05 7 Hours · Market Basket Analysis

Association Rule Mining: Apriori, ECLAT & FP-Growth

Complete exam-style numerical derivations for Support, Confidence, Lift, Apriori horizontal candidate pruning, ECLAT vertical TID-set intersections, and FP-Tree prefix compression.

05.1 Key Metrics: Support, Confidence & Lift

5-Mark Master Answer
1. Definition & Importance (1 Mark)

Association Rule Mining discovers strong co-occurrence relationships ($X \to Y$) among frequent itemsets in large transactional databases (Market Basket Analysis) to power cross-selling, store layout, and recommendation engines.

2. Core Mathematical Measures (3 Marks)
$$\text{Support}(X \to Y) = \frac{\text{Transactions containing }(X \cup Y)}{N}$$ $$\text{Confidence}(X \to Y) = \frac{\text{Support}(X \cup Y)}{\text{Support}(X)} = \frac{\text{Count}(X \cup Y)}{\text{Count}(X)}$$ $$\text{Lift}(X \to Y) = \frac{\text{Confidence}(X \to Y)}{\text{Support}(Y)} = \frac{P(X \cup Y)}{P(X)\cdot P(Y)}$$

Support decides whether an itemset is frequent; Confidence decides whether a rule is strong; Lift measures true correlation ($\text{Lift} > 1$ = positive association, $= 1$ = independent, $< 1$ = negative substitution).

3. Exam Flow Shortcut (1 Mark)

Apriori Pipeline: $\text{Transactions} \to C_1 \to L_1 \to C_2 \to L_2 \to C_3 \to L_3 \to \text{Association Rules}$, where $C$ = Candidate itemsets and $L$ = Large/Frequent itemsets.

05.3 Solved Example 2: Apriori {A, B, C}

Source Exam

Transactions: T1:{A,B,C}, T2:{A,B}, T3:{A,C}, T4:{A,B,C}, T5:{B,C}. Min Support = 60% (Count = 3), Min Confidence = 70%.

  • $L_1$: {A}: 4 (T1,T2,T3,T4), {B}: 4 (T1,T2,T4,T5), {C}: 4 (T1,T3,T4,T5) — All 80% frequent.
  • $L_2$: {A,B}: 3 (T1,T2,T4), {A,C}: 3 (T1,T3,T4), {B,C}: 3 (T1,T4,T5) — All 60% frequent.
  • $C_3 \to L_3$: {A,B,C} appears only in T1 & T4 → Support $= 2/5 = 40\% < 60\% \implies L_3 = \emptyset$.
  • 6 Strong Rules: $A \to B, B \to A, A \to C, C \to A, B \to C, C \to B$ all have Confidence $= 3/4 = \mathbf{75\%} \ge 70\%$ ($\text{Lift} = 0.75/0.80 = 0.94$).

05.5 FP-Growth Solved Walkthrough & Algorithm Comparison

Tree Mining

FP-Growth (Frequent Pattern Growth) eliminates candidate generation ($C_k$) by compressing transactions into a prefix-sharing FP-Tree in just two database scans:

  1. Scan 1 (Support Count): Using Example 1 (Min Count = 3), frequent items sorted descending: Bread:4, Milk:4, Diaper:4, Beer:3. (Eggs, Cola dropped).
  2. Sort Transactions by Frequency:
    • T1: Bread, Milk
    • T2: Bread, Diaper, Beer
    • T3: Milk, Diaper, Beer
    • T4: Bread, Milk, Diaper, Beer
    • T5: Bread, Milk, Diaper
  3. Scan 2 (Insert into FP-Tree) & Mine Conditional Pattern Bases: Shared prefixes (like Bread → Milk in T1, T4, T5) merge into single nodes with incremented counts, then conditional FP-trees are mined bottom-up from Beer → Diaper → Milk.

Python Demo: Apriori & Association Rules (mlxtend) 
import pandas as pd
from mlxtend.preprocessing import TransactionEncoder
from mlxtend.frequent_patterns import apriori, association_rules

transactions = [
    ["Bread", "Milk"],
    ["Bread", "Diaper", "Beer", "Eggs"],
    ["Milk", "Diaper", "Beer", "Cola"],
    ["Bread", "Milk", "Diaper", "Beer"],
    ["Bread", "Milk", "Diaper", "Cola"]
]

te = TransactionEncoder()
df = pd.DataFrame(te.fit_transform(transactions), columns=te.columns_)

freq_items = apriori(df, min_support=0.60, use_colnames=True)
rules = association_rules(freq_items, metric="confidence", min_threshold=0.70)
print(rules[["antecedents", "consequents", "support", "confidence", "lift"]])
